# A 9-State Markov Chain Model for Semi-Fixed Menstruation Patterns

**PhD Research** — Probabilistic and Statistical Analysis of the Menstrual Cycle from a Halachic Perspective  
**Author:** Dvir Ross, Shenkar College · dvirross@shenkar.ac.il  

---

## Abstract

This repository contains the complete computational analysis supporting the paper
*"A 9-State Markov Chain Model for Semi-Fixed Menstruation Patterns: Stationary
Distribution and Population Heterogeneity"*.

We model the longitudinal dynamics of menstrual cycle lengths as a finite Markov chain
with 9 states, defined by the **semi-fixed menstruation (וסת חצי קבוע)** construct in
Jewish Halachic law. The stationary distribution — computed analytically via eigenvalue
decomposition and validated by Monte Carlo simulation — yields the first probabilistic
estimate of the long-run proportion of cycles falling in **favorable semi-fixed states**
(S31 and S33), where no additional pre-menstrual abstinence is required.

We further show, using Kruskal-Wallis and Bonferroni-corrected Dunn post-hoc tests, that
clients who ever enter each semi-fixed sub-type (S31/S32/S33) differ significantly in their
cycle-length distributions — motivating sub-population analysis via group-specific sub-chains.

**Target journal:** *Mathematics* (MDPI) — Q1, Applied Probability / Markov Chains

## Data

The analysis uses `datasets/FilteredData.csv` from the parent repository — a
Natural Family Planning (NFP) dataset of **1,554 cycles** from **116 clients**
(≥ 5 cycles each), with the primary variable `LengthofCycle` incremented by 1
to reflect the Halachic counting convention.
